# Мерч 1С

Каталог мерча 1С: 20 товаров с фотографиями, ценами и характеристиками. У каждого товара отдельная страница.

## Открыть сайт

Откройте `index.html` в браузере. Все стили и изображения находятся в проекте.

## Структура

| Путь | Содержимое |
| --- | --- |
| `index.html` | Главная, популярные товары, отзывы и контакты |
| `catalog.html` | Каталог и переходы к категориям |
| `product.html` | Страница бирюзовой футболки |
| `products/*.html` | Страницы остальных 19 товаров |
| `order.html` | Страница заявки с выбором товара из каталога |
| Страницы товаров | Окно заказа для выбранного товара |
| `faq.html` | Вопросы и ответы |
| `css/custom.css` | Цвета, карточки, изображения и оформление форм |
| `vendor/bootstrap/css/bootstrap.min.css` | Локальные стили Bootstrap 5.3.8 |
| `vendor/bootstrap/js/bootstrap.bundle.min.js` | Локальный Bootstrap JS Bundle 5.3.8 |
| `images/` | Фотографии товаров |

## Оформление

Адаптивная сетка построена на классах Bootstrap `container`, `row`, `col-*` и `g-*`. Использованы `navbar`, `card`, `badge`, `btn`, `alert`, `form-control`, `input-group` и `form-check`. Дополнительные правила находятся в `css/custom.css`.

Категории каталога связаны с разделами страницы якорными ссылками. На узком экране меню раскрывается компонентом Bootstrap Navbar/Collapse через локальный JS Bundle. Популярные товары переключаются штатным компонентом Bootstrap Carousel. Окна заказа открываются и закрываются компонентом Bootstrap Modal, вопросы FAQ — элементом `details`. На странице `order.html` товар выбирается через `form-select`. Формы используют встроенную проверку браузера и показывают подтверждение после заполнения. Заявки и отзывы не отправляются: это учебный макет без сервера.

## Проверка

1. Откройте каталог и проверьте все 20 карточек.
2. Перейдите на страницы нескольких товаров и проверьте изображения, характеристики и обратную ссылку.
3. Заполните формы и проверьте обязательные поля.
4. Сузьте окно браузера и проверьте раскрытие меню и расположение карточек.
